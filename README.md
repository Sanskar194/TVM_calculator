## Project Overview

Time Value of Money (TVM) is an important concept in finance which states that the value of money changes over time due to factors such as interest and investment returns.

This project provides a simple and user-friendly web application for performing common TVM calculations used in real-life financial decision-making.

The application includes:

1. Future Value Calculator
2. Present Value Calculator
3. Simple Interest Calculator
4. Compound Interest Calculator
5. EMI Calculator
6. Loan Amortization Schedule
7. Scenario Analysis
